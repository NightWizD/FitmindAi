# Instruction
Always apply the following visual style when creating or editing UI components:

## Color Palette
- **Background**: Deep Navy Slate (#0F172A)
- **Primary Accent**: Electric Blue (#3B82F6)
- **Secondary Accent**: Cyan (#22D3EE)
- **Surface**: Dark Slate (#1E293B) with subtle 1px border (#3B82F6, opacity 0.2)
- **Text**: Pure White (#FFFFFF) for headers, Slate-400 (#94A3B8) for subtext.

## Shapes & Layout
- **Corner Radius**: 24px - 32px for all main containers and cards.
- **Elevation**: Use subtle glows (Shadows with primary blue color) instead of gray shadows.
- **Glassmorphism**: 10% opacity white overlays for interactive elements.

## Typography
- **Primary**: Inter, Sans-Serif.
- **Header**: Bold, high contrast.
- **Body**: Medium, spacious line-height (1.6).

## Components
- **Progress**: Circular indicators with glowing trails.
- **Buttons**: Pill-shaped with subtle blue-to-deepblue gradients.
- **Navigation**: Minimalistic bottom bar with subtle icons.
